mini NACCS → SXGW → PORT-IT（疑似システムの流れ）

① mini-NACCS（MiniNaccsGen）
アプリ

コンソールで入力 → NACCS 風の電文ファイルを生成

  • ファイル出力先: /Users/egamijun/NaccsInbox
  • HDR / DTL 行を持つテキスト
➡
② NxReceive（SXGW 受信）
ジョブ

NaccsInbox のファイルを読み、通知テーブルに登録

  • 読み込み: NaccsInbox/*.txt
  • INSERT: T_NaxTantei (Status = 'WAIT')
  • 処理済みファイルは NaccsProcessed へ移動
➡
③ T_NaxTantei（SXGW 通知テーブル）
DBテーブル

NACCS 通知を一時的に貯める場所

  • キー: VslCode, VoyNo, ContainerNo
  • 許可日: PermitDate
  • 許可時刻: PermitTime
  • 状態: Status = WAIT / DONE / ERROR
④ FollowJob（後続JOB）
ジョブ

未処理通知 (WAIT) を読んで、コンテナ本体を更新

  • T_NaxTantei から WAIT を取得
  • T_CyContainer を検索（船＋Voy＋コンテナ）
  • 見つかれば → 許可情報を UPDATE
  • 通知側は DONE / ERROR に変更
➡
⑤ T_CyContainer（コンテナ在庫）
DBテーブル

港湾システム本体のコンテナ情報

  • キー: VslCode, VoyNo, ContainerNo
  • 許可フラグ: PermitFlag (0→1)
  • 許可日時: PermitDateTime
  • 最終 NACCS メッセージ: LastNaccsMsg
